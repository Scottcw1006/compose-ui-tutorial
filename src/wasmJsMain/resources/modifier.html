Modifier

在 XML 裡，尺寸、padding、背景、點擊事件分散在一堆 attribute 與 setOnClickListener 中。Compose 把這些全部統一成 Modifier：一條可以串接的裝飾鏈，套在任何 Composable 上。

順序很重要

說明

這是從 View 系統轉過來最容易踩的坑。Modifier 會由外而內、依序套用，每一個 Modifier 都包住後面的所有東西。所以 padding 寫在 background 前面，留白就在色塊外（像 margin）；寫在後面，留白就在色塊內（像 padding）。

這也是為什麼 Compose 沒有 margin —— 你只需要調整 padding 的位置。

clickable：點擊與水波紋

說明

Modifier.clickable 取代 setOnClickListener，同時自動提供 Material 水波紋（ripple）與無障礙語意。

注意順序再次登場：clip 要寫在 clickable 前面，水波紋才會被裁成圓角；反過來寫，水波紋會是方形的超出圓角。

形狀：clip、border、shadow

說明

過去要做圓角或陰影，需要建立 shape drawable XML、設定 elevation 與 outlineProvider。在 Compose 中，形狀是一個 Shape 物件，可以直接傳給 clip、border、background、shadow。

  • CircleShape：圓形
  • RoundedCornerShape(16.dp)：圓角，也可以四個角各自指定
  • CutCornerShape(...)：切角

慣例：自訂 Composable 時，第一個選填參數一律命名為 modifier: Modifier = Modifier，並套用在最外層元件上。這讓呼叫端可以從外部調整你的元件，是 Compose 官方 API 都遵守的規則。
