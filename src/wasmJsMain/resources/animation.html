CCompose 實戰教學

第 5 章 · 動畫與特效

動畫基礎

在 View 系統做動畫，要在 ValueAnimator、ObjectAnimator、TransitionManager、MotionLayout 之間挑選。Compose 的動畫建立在「狀態」之上：你只要改變狀態，告訴 Compose 要用什麼方式過渡，剩下的它會處理。

animate*AsState：最簡單的動畫

說明

把原本寫死的目標值，換成 animateDpAsState、animateColorAsState、animateFloatAsState… 就完成了。每當 targetValue 改變，它會從目前的值平滑地動畫到新值 —— 動畫進行到一半再點一次，也會自然地轉向，不會跳回起點。

animationSpec 決定動畫的「手感」：

  • spring(...)：物理彈簧，預設值，適合大部分互動。
  • tween(durationMillis, easing)：固定時長，搭配 easing 曲線。

AnimatedVisibility：出現與消失

說明

取代 view.visibility = View.GONE 再自己做淡出。enter / exit 用 + 組合多種效果：fadeIn、slideIn*、expand*、scaleIn…

使用 expandVertically / shrinkVertically 時，元件佔用的空間也會一起變化，所以下方的內容會平滑地移動，而不是瞬間跳上去。

AnimatedContent：內容切換

說明

當同一個位置要從 A 內容換成 B 內容（數字、分頁、載入中 → 結果），用 AnimatedContent。transitionSpec 可以讀到 initialState 與 targetState，依「變大還是變小」選擇不同方向，togetherWith 把進場與退場動畫組合起來。

重點是 lambda 參數 value：一定要用它，而不是外面的 count，否則退場中的舊內容也會顯示新數字。

animateContentSize：尺寸自動補間

說明

只要加上一行 Modifier.animateContentSize()，元件因為內容改變而變大、變小時，就會自動動畫過渡。展開 / 收合的卡片、可展開的說明文字，用它最省事。

和其他 Modifier 一樣要注意順序：它要放在 size、defaultMinSize 這類尺寸 Modifier 之前，動畫才會平滑。

updateTransition：一個狀態驅動多個動畫

說明

當多個屬性要跟著同一個狀態一起變化時，與其寫好幾個獨立的 animate*AsState，不如用 updateTransition。所有子動畫會同時開始、由同一個狀態統一管理（各自何時結束取決於各自的 animationSpec），也能在 Android Studio 的 Animation Preview 中逐幀檢查。

rememberInfiniteTransition：無限循環

說明

Loading、呼吸燈、骨架屏的閃爍效果，都屬於「沒有結束狀態」的動畫，用 rememberInfiniteTransition 搭配 infiniteRepeatable。RepeatMode.Reverse 會來回播放，Restart 則每次從頭開始。

這裡用 graphicsLayer 套用縮放與旋轉：它只在繪製階段生效，不會觸發重新量測與排版，是做高頻率動畫時效能最好的方式。第 8 章「graphicsLayer 視覺特效」會更深入介紹它。

效能提示：在 graphicsLayer { }、Modifier.offset { }、drawBehind { } 這類 lambda 版本的 Modifier 中讀取動畫值，Compose 可以跳過重組、只重新繪製。高頻動畫優先考慮這些寫法。
