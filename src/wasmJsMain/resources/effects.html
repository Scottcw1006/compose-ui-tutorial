CCompose 實戰教學

第 8 章 · 動畫與特效

graphicsLayer 視覺特效

Modifier.graphicsLayer 把元件繪製到一個獨立的圖層上，再對整個圖層做縮放、旋轉、透明度、裁切與合成。它相當於 View 的 setScaleX、setRotationY、setAlpha 加上 setLayerType(LAYER_TYPE_HARDWARE)，是做出流暢特效的核心工具。

變形與透明度

說明

graphicsLayer { } 的屬性只影響繪製，不影響排版：元件放大兩倍，佔用的空間還是原本的大小，也不會推擠旁邊的元件 —— 和 View 的 scaleX 行為一致。

因為使用 lambda 版本，滑桿拖動時只會更新圖層屬性並重新繪製，不會重組也不會重新排版，這也是它適合做動畫的原因。

不要在 lambda 裡使用和 GraphicsLayerScope 屬性同名的變數，例如區域變數 alpha。alpha = alpha 會被解析成區域變數指派給自己，圖層的透明度根本不會改變。範例中刻意命名為 opacity。

3D 翻轉卡片

說明

rotationX / rotationY 讓元件繞 X 軸或 Y 軸做 3D 旋轉。兩個細節決定效果好不好：

  • cameraDistance：預設的相機距離很近，翻轉時邊緣會誇張地放大。拉遠一點（例如 12f * density）效果較自然。
  • 轉過 90 度時切換內容：背面要再套一次 rotationY = 180f，否則文字會左右相反。

漸層動畫：骨架屏閃光

說明

載入中的骨架屏（skeleton）是由一條移動的 linearGradient 構成的：用無限動畫讓漸層的起點從元件左側外面一路移動到右側外面。

重點在 shimmer 這個自訂 Modifier 接收的是 () -> Float 而不是 Float：動畫值只會在 drawBehind 裡、也就是繪製階段被讀取，所以每一幀只重畫，畫面上十幾個閃光元件完全不會重組。這是 Compose 效能最佳化中最常用的技巧：盡量把讀取狀態的時間點往後延。

BlendMode：聚光燈遮罩

說明

想在圖層上「挖洞」，需要兩個步驟：

  1. compositingStrategy = CompositingStrategy.Offscreen：先把這一層畫到一張獨立的離屏緩衝區。少了這一步，挖洞時會連底下的內容一起挖掉，只剩一片黑。
  2. 先畫滿一層深色，再用 BlendMode.DstOut 畫一個放射漸層的圓：圓越不透明的地方，遮罩被擦掉越多，就形成柔邊的聚光燈。

指標位置用的是底層 API awaitPointerEventScope：它能收到滑鼠懸停時的移動事件，這是 detectDragGestures 這類高階偵測器做不到的。

模糊效果

說明

Modifier.blur(radius) 會模糊元件及其所有子元件，常用在對話框背後、或隱藏敏感內容。

Android 版本限制：在 Android 上，blur 依賴 RenderEffect，只在 Android 12（API 31）以上生效，舊版本會直接忽略、顯示清晰的內容。需要支援舊裝置時，請準備替代設計，例如半透明遮罩。
