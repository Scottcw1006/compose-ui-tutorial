CCompose 實戰教學

給 Android 開發者的 Jetpack Compose 教學

從 XML 到 Compose，
邊看邊玩邊學

你已經會寫 Android，熟悉 Activity、RecyclerView 與 XML layout。這份教學不從零講 Kotlin，而是直接對照你熟悉的 View 系統，帶你從排版一路走到動畫與特效。

每一節都有三個部分

  • 說明：觀念是什麼、和 View 系統的差別、常見的坑。
  • 代碼：可以直接複製到專案使用的 Composable。
  • 實際呈現：右側的手機框不是截圖，而是同一段 Compose 代碼透過 Compose Multiplatform 編譯成 WebAssembly，真的在你的瀏覽器中執行 —— 可以點、可以滑、可以打字。
