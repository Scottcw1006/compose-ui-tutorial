CCompose 實戰教學

第 1 章 · 基礎排版

Column、Row、Box

Compose 的排版只靠三個基本容器就能組出絕大多數畫面。如果你熟悉 XML，可以把它們想成更輕量、可以任意巢狀而不怕效能問題的 LinearLayout 與 FrameLayout。

ComposeView 系統中最接近的東西用途
ColumnLinearLayout（vertical）子元件由上往下排
RowLinearLayout（horizontal）子元件由左往右排
BoxFrameLayout子元件互相疊加

Column：垂直排列

說明

Column 會把子元件由上往下依序放置。兩個最常用的參數：

  • verticalArrangement：控制子元件在主軸（垂直方向）上怎麼分配空間，例如 Arrangement.spacedBy(8.dp) 讓每個子元件之間固定間隔 8dp —— 不用再對每個 View 設 marginTop。
  • horizontalAlignment：控制子元件在交叉軸（水平方向）上的對齊，相當於 android:gravity。

Row：水平排列

說明

Row 是水平版的 Column，參數名稱也對調：horizontalArrangement 管主軸、verticalAlignment 管交叉軸。

下面這個「列表項目」是 App 中最常見的排版：左邊頭像、中間兩行文字、右邊操作元件。中間的 Column 加上 Modifier.weight(1f)，就會吃掉所有剩餘寬度，把 Checkbox 推到最右邊。

為什麼可以放心巢狀？ View 系統裡多層 LinearLayout 搭配 weight 會造成多次 measure，所以我們習慣改用 ConstraintLayout 攤平。Compose 的排版規定每個子元件只能被量測一次，巢狀的成本很低，直接用 Row / Column 組合通常就是最好的寫法。

Box：疊加排版

說明

Box 把所有子元件疊在一起，後宣告的在上層。contentAlignment 決定預設對齊位置，個別子元件也可以用 Modifier.align(...) 覆寫 —— 這個 align 只在 BoxScope 裡才能使用，編譯器會幫你擋掉錯誤用法。

常見用途：在圖片上疊文字、角落的通知徽章（badge）、在內容上蓋一層 loading。

Arrangement：分配主軸空間

說明

當容器比子元件總寬度更大時，Arrangement 決定多出來的空間怎麼分配。SpaceBetween、SpaceAround、SpaceEvenly 的差別光看文字很難記，直接點下面的選項切換看看。

  • SpaceBetween：頭尾貼齊邊緣，中間平均分配。
  • SpaceAround：每個子元件兩側的空間相等，所以邊緣空間是中間的一半。
  • SpaceEvenly：所有間隔（包含邊緣）完全相等。

weight：按比例分配

說明

Modifier.weight() 和 layout_weight 的概念相同：先量測固定尺寸的子元件，剩下的空間再依權重比例分配。不同的是，你不需要再寫 layout_width="0dp" 這種技巧。

另一個實用技巧：在 Column 中放一個 Spacer(Modifier.weight(1f))，它會撐開所有剩餘空間，把後面的元件推到底部。

weight 只存在於 RowScope 與 ColumnScope，所以只能用在 Row / Column 的直接子元件上。
